## ✨ About

Legacy Mini Bot is a lightweight version of Legacy MD, designed for users who need a fast, simple and stable WhatsApp bot without unnecessary features.

It includes only the most useful commands while maintaining excellent performance and low resource usage.

---

# 🚀 Features

- ✅ Multi Device Support

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/SAT-Limited-Organization/Legacy-Mini-Bot.git
```

Move into the project

```bash
cd Legacy-Mini-Bot
```

Install dependencies

```bash
npm install
```

Start the bot

```bash
npm start
```
